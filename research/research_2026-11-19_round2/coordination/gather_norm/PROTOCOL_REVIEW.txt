Memory ownership/protocol:
- Push plane is borrowed from the already-reserved projection communicator.
- Dense phase payload layout is [rank,M,H/world], identical to native gather.
- Every16Bvector belongs to one producer rank and one destination(row,col).
- Width is divisible by world*8, so no vector crosses a rank's slice.
- Both original gather and fused receiver rewrite each +0 BF16 to-0. This differs
  from the separate all-reduce's32bitpair marker; do NOT mix their marker tests.
- Receive checks every16bitlane and clears exactly the vector it consumed.
- ForC1, blocks0..grid-1 own counters;block0 flips countersgrid..capacity-1.
  Native gather reserves its lastblock for the matching tail update. A CPU index
  model passed768 alternating native/fused transitions and varyingrowcounts.
- Every operation advances ALLcounters, includingunusedones, to the same phase.
- Two phase halves are safe under common collective order and dependency-ordered
  streams: a rank cannot publish phaseN+2 until consuming N+1 from everypeer;
  eachpeer publishesN+1 onlyafterits prior operation has clearedN locally.
- This is source reasoning, not an observed NVLink/multicast liveness proof.
