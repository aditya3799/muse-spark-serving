## Target-verify input staging

DFlashVerifyInput.prepare_for_verify originally loads graph buffers before returning. DFlashWorkerV2 then restores the schedule batch's host lengths, applies the existing DP guards, and forwards the separate ForwardBatch object to the target. ForwardBatch.init_new already captured the verify lengths. TpWorker's skip flag marks the ForwardBatch preplanned. DecodeCudaGraphRunner.execute calls load_batch again, and that branch calls _copy_replay_inputs for IDs and positions. Its identity shortcut is DSpark-only. The scoped candidate defers the first graph plan only for eligible CUDA DFlash batches, leaves eager planning and DP/NPU semantics intact, and lets execute perform the one required static fill.
