# Historical research archive

This folder preserves source variants, analysis/build scripts, and written experiment records from the original workspace. Names and relative paths are retained where possible. These files include successful, unsuccessful, superseded, and unqualified work. Some historical variants violated the applicable numerical or source-format rules; they are not the selected submissions.

Use the parent track README for current results and selected artifacts. Older notes may name then-current baselines, ranks, quotas, dates, or next actions that were later superseded. They are historical observations, not instructions to launch new experiments or submissions.

This archive excludes credentials, caches, generated binaries, model weights, full vendor checkouts, duplicated dependency/source snapshots, official evaluator files, and most runtime logs. Some scripts consequently require the original workspace or upstream dependencies and are preserved for study rather than advertised as directly runnable.
