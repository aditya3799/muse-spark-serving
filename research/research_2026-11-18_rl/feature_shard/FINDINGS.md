# Splitting output features across paired expert ranks

Each pair owns the union of its original experts. The first matrix multiply computes matching gate and up columns with the full reduction dimension. The two ranks exchange their BF16 activations. The second matrix multiply computes complementary hidden features, again with the full reduction dimension. One FP32 sum of squares per live route provides the shared expert norm. Each original rank and each feature shard retain their own BF16 partial sums. A final exchange restores the original per-rank feature vector before the usual expert-parallel reduction.

The first prototype combined the two original expert owners before the BF16 rounding step. On eight Gloo ranks, that changed about half the elements on mixed routes and produced a maximum relative L2 difference of 0.004142. Restoring both original rounding boundaries and the EP sum order eliminated all observed bit differences. The revised method matched all 37,888 output values on each of the four-rank and eight-rank tests. Each test used two seeds, four routing patterns, 16 synthetic experts, 37 rows and 128 output features. These checks exercise real CPU collectives. The model's hidden width is 4096. The new local GPU implementation runs both partial Humming matrix multiplies with frozen release packing, actual top-eight routing and FP32 accumulation. Both original and modified rank computations execute serially on one device. This independently checks the math of both rank legs.
