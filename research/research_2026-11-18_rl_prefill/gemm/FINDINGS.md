# Route-index staging within W13 and W2

The candidate uses one coalesced load per sorted slot to publish both the output slot and the input row before the next matrix tile. The scoped path uses ordinary load-thread scheduling, indexed NVFP4 weights and a full-K FP32 accumulator. For W13 the input row is the slot divided by eight. For W2 it is the slot itself. All other cases select the scored helper. The dependency's matrix multiplication, activation, weight layout and epilogue remain the scored implementation. The SGLang wrapper builds a separate native CUDA kernel, reuses Humming's own registrar and launcher, and never edits the installed Humming files.

The cumulative patch applies to the exact scored parent, SHA256 8c7547213fb993a318321a26f84e2872db8c87b358ee3d3ea638695702b0dc2b.
